# 🌐 Personal Portfolio Website

A responsive personal portfolio website showcasing my background, technical projects, leadership experiences, and professional journey. The site serves as a central hub for recruiters, collaborators, and peers to learn more about my work in **Business Analytics, Computer Science, Machine Learning, Cybersecurity, and Finance**.

Designed with **HTML5, CSS3, and JavaScript**, the website features a modern, responsive layout highlighting my projects, internship experiences, leadership roles, organizations, and ways to connect.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/armirchandani/github.io.git
```

Navigate into the project

```bash
cd github.io
```

Open the website

```bash
index.html
```

or simply double-click **index.html** in your browser.

---

# 🚀 Usage

The website can be customized by updating:

- Personal biography
- Experience
- Featured projects
- Organizations
- Images
- Resume
- Contact information
- Social media links

To publish changes:

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```

GitHub Pages will automatically deploy the updated website.
